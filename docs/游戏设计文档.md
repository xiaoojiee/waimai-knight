# 《你的胆子真的是肥嘟嘟的》游戏设计文档

> 2D 俯视角外卖骑手无尽跑酷 ｜ H5 / B站 Toy

---

## 0. 切入点

**一句话**：把外卖骑手真实的“生死时速”，做成能笑出声的俯视角跑酷。

**玩法原型**
- 经典街机射击的移动手感（雷霆战机式：画面自动前推，玩家只管走位）
- 外卖骑手题材：接单、送餐、超时罚款、逆行、被撞
- 无尽跑酷：越跑越快、越跑越乱、比谁跑得远

**文化锚点（B站梗）**

| 梗 | 落点 |
| --- | --- |
| 「你的胆子真的是肥嘟嘟的」 | 游戏名 / 罪恶值系统的设计动机（胆子越肥，越敢乱来） |
| 「牛来」 | 载具「牛来」（投币解锁，吃外卖冲刺） |
| 「心脏还有点问题」 | 载具「火车头」描述（持续掉血） |
| 黑袍纠察队 · 火车头 | 载具「火车头」原型（极快、高伤、持续掉血） |
| 「逆行大运」 | Boss：逆行、只露车头、随机变道冲撞 |
| 华强买瓜 | 特殊外卖「西瓜」+ 瓜摊老板客户 |
| 杰哥不要 | 特殊外卖「啤酒」+「我超勇的」增益 |
| 良子 | 特殊外卖「焖子」+ 味真足 |
| 鸡汤来咯 | 特殊外卖「鸡汤」（全部外卖变毒） |
| 西湖醋鱼 / 豆汁儿 | 有毒外卖的两种外观 |

**设计基调**：快、乱、爽；失败不憋屈（掉血有缓冲，钱不够只是被撞飞）。

## 2. 核心循环

```
选载具 → 出发 → 一路冲：躲避 / 撞开竞争对手抢外卖
   → 按时把外卖送到路边客户赚外快（送不够要赔钱）
   → 用钱在店里买外卖 / 买道具
   → 撞车掉血、超速涨罪、警车追捕、大运逆行
   → 血量清空（死亡）或金钱清零（破产）
   → 结算里程 → 上传排行榜 → 再来一局
```

**爽点节奏**：提速（失控）→ 撞飞对手抢货（破坏）→ 送达结算（收益）→ 大运登场（危机）→ 冲榜（证明）。

## 3. 操作

| 输入 | 作用 |
| --- | --- |
| `WASD` / `方向键` | 上下左右移动（**上 = 加速，下 = 刹车**） |
| `空格` | **主动吃外卖回血**（牛来额外触发冲刺） |
| `Esc` | 暂停 / 继续 |
| 触屏下半屏滑动 | 虚拟摇杆（偏移越大越快，松手回中） |
| 触屏右下按钮 | 「吃外卖 / 冲刺」「**投掷外卖**」 |

**测试模式**：连续输入 `hsgg` 开启。开启后：`1~4` 装备、`5` +5 外卖、`6` 有毒外卖、`7` 特殊外卖、`8/9/0` 特殊效果、`P` 全变毒、`B` 生成大运、`T` +500m、`+/-` 罪恶等级。

> 设计原则：移动只有“上下左右”，其余交给自动系统（自动瞄准、自动吃外卖、自动牵引），降低操作负担。

## 4. 玩法系统

### 4.1 总览（控制外卖小哥送外卖）

| 项 | 规则 |
| --- | --- |
| 目标 | 控制外卖小哥送外卖，送到赚钱，送不够赔钱 |
| 死亡 | **血量清空 → 死亡**（游戏结束） |
| 破产 | **金钱清零 → 破产**（游戏结束） |
| 回血 | 血量偏低会**自动吃外卖**回血；也可**主动吃**（空格 / 按钮） |
| 攻击 | 可**丢出外卖**对敌人造成伤害（自动锁定） |

### 4.2 外卖获取（3 种途径）

| 途径 | 说明 | 数量 |
| --- | --- | --- |
| ① 路上拾取 | 路边随机掉落，风险最低 | 少量 |
| ② 撞倒竞争对手抢夺 | 撞飞敌方骑手，掉落其外卖 | 由其携带量决定 |
| ③ 去店里花钱买 | 水泥区「饭店」，一次买一批 | 一次 5 个起（随里程增加） |

### 4.3 送餐（收益与惩罚）

| 项 | 规则 |
| --- | --- |
| 客户位置 | 路边左右随机，随场景向后移动 |
| 需求数量 | 随里程增长（每 500m 升 1 档，另加难度额外 0~3 个） |
| **送达** | **+20 / 个** |
| **没送够** | **-8 / 个**，金钱 < 0 → 破产 |
| 送达后 | 客户朝人行道走开并淡出 |
| 特殊客户 | 不看数量，交付对应特殊外卖 → 触发增益（见 §7） |

### 4.4 行驶

#### 4.4.1 行驶控制
| 量 | 规则 |
| --- | --- |
| 前进速度 | `载具基础速度 × 节奏系数`，减去玩家上下移动分量 |
| 节奏系数 | `1 + 每公里 15%`（不设上限；火车头有速度软上限 1200 px/s） |
| 刹车 | 向后推得越狠减速越多，各载具刹车系数不同 |
| 走位 | 仅限在路面内左右移动，可主动撞竞争对手 |
| 侧倾 | 左右移动时车身侧倾，速度感反馈 |

#### 4.4.2 行驶环境
| 区域 | 规则 |
| --- | --- |
| 沥青路面 | 主战场，安全但拥挤 |
| 水泥区（右侧人行道） | 停留超 2s 开始涨罪恶值 |
| 施工路段 | 占用半边车道（黄色斜纹 + 警告牌），驶入涨罪恶值 |
| 里程推进 | 越远 → 速度更快、敌人更多、事件更频繁 |

#### 4.4.3 行驶事件（随机触发）
| 事件 | 触发 | 内容 |
| --- | --- | --- |
| 路边客户 | 每 40~100m | 送到赚外快，送不够赔钱 |
| 装备店铺 | 50m 后每 100~200m | 撞上去自动购买道具 |
| 饭店 | 120m 后每 130~260m | 一次买一批外卖 |
| 施工路段 | 120m 后每 200~400m | 挤占车道，制造走位压力 |
| 警车追捕 | 罪恶 ≥ 2 级 | 下方跟踪 + 间歇前冲撞你 |
| 拦车钉 | 罪恶 4 级 | 前方随机车道埋钉，碾过减速 4s |
| 逆行大运 | 1km 后每 400~700m | 顶部悬停、变道、前冲 |
| 特殊客户 | 约 15~40% 概率 | 交付特殊外卖触发强力增益 |

## 5. 罪恶值系统（体现「胆子肥嘟嘟」）

**攒槽来源**
| 来源 | 速率 |
| --- | --- |
| 超速行驶（超过限速，平方曲线） | `((速度-限速)/200)² × 45 /s` |
| 行驶在施工路段（占用车道内） | `14 /s` |
| 水泥区停留超过 2s | `12 /s` |

- 槽满 100 → **升 1 级并清槽**（最高 4 级）
- 停止违规 2s 后槽开始衰减；槽空则降 1 级（最低 1 级）

**等级影响**
| 等级 | 效果 |
| --- | --- |
| 1 级 | 无影响 |
| 2 级 | **1 辆警车**追击 |
| 3 级 | **2 辆警车**（左右各一，错开冲撞） |
| 4 级 | 追加**道钉**妨碍 |

- 之后罪恶值继续累计（满级过载）→ **持续提升警车冲撞频率与道钉刷新率**（无上限）

**警车行为**：屏幕最下方跟踪，间歇前冲（520 px/s）撞玩家 **-33 HP** + 弹开 + 震屏；会主动撞大运（120 伤害）；撞到竞争对手直接秒杀抢外卖。

**道钉**：前方 1500px 随机一条车道生成，碾过 → 减速 4s。

## 6. 经济系统

> 送外卖赚的钱，既能**买外卖**，也能**买道具**。

| 道具 | 价格 | 效果 |
| --- | --- | --- |
| 手枪 | 70 | **6 发**子弹，自动攻击敌方骑手 |
| 步枪 | 120 | **20 发**子弹，自动攻击敌方骑手 |
| 匕首 | 40 | **5 次**攻击内**大幅提升撞击伤害**（撞击附加 15 伤害） |
| 护盾 | 60 | **抵挡 3 次伤害** |

- 枪械互斥（手枪 / 步枪只能有一种）；匕首与护盾可共存
- 子弹同样能打大运
- 水泥区「饭店」也可花钱买外卖（单价 10，一次一批）
- **价格随里程缓慢提升**：`1 + 难度 × 0.35`（每 2000m +35%，无上限）
- 钱不够撞上店铺 → 被撞飞并 **-20 HP**

## 7. 特殊外卖

### 7.1 有毒外卖
- 外观参考：**西湖醋鱼 / 豆汁儿**（两种随机）
- **丢出**：对敌人造成**大量伤害**（25，普通投掷仅 8）
- **误食**：**扣血**（-15 HP）
- 可以**当正常外卖送出**（不额外加成，但能凑数量）

### 7.2 特殊外卖（4 种）

| 特殊外卖 | 梗来源 | 对应客户 | 效果 |
| --- | --- | --- | --- |
| **西瓜** | 华强买瓜 | 瓜摊老板 | 获得**匕首**（西瓜刀）；短时间内自动丢**生瓜蛋子**攻击敌人；命中**+30 块** |
| **啤酒** | 杰哥不要 | 杰哥 | 获得短暂「**我超勇的**」状态：撞击伤害提升、减伤；撞到敌方触发阿伟台词 |
| **焖子** | 良子 | 良子 | 短时间内**撞死敌方骑手可将其吃掉回血**（+50 HP）；播放「味真足」 |
| **鸡汤** | 鸡汤来咯 | 炊事员 | **给所有食物下毒**：现有外卖全部变成有毒外卖 |

**数值**
| 增益 | 时长 | 细节 |
| --- | --- | --- |
| 我超勇的 | 6s | 速度 ×2.8、受伤 ×0.25、罪恶积累 ×0.02 |
| 西瓜摊 | 8s | 自动丢西瓜间隔 0.7s，15 伤害，命中 +30 |
| 焖子 | 8s | 撞死敌人被吃，+50 HP |
| 鸡汤 | 立即 | 全部外卖变毒 |

- 持有对应特殊外卖时，该特殊客户出现概率显著提升

| 载具 | 解锁 | 定位 | 关键数值 | 特点 / 缺点 |
| --- | --- | --- | --- | --- |
| **步行** | 初始 | 最差但稳健 | 血 60 ｜ 速 112（上限 224） | 撞击伤害 ×0.5；水泥区不涨罪恶值 |

## 11. 难度与进度

| 系数 | 公式 |
| --- | --- |
| `difficulty()` | `里程(米) / 2000`（无上限） |
| `pace()` | `1 + 公里数 × 0.15`（无上限） |
| 大运强度 | `1 + difficulty() × 1.0` |
| 店铺价格 | `1 + difficulty() × 0.35` |

所有刷新间隔/需求都设了**安全下限或封顶**（敌人间隔 ×0.2、同屏敌人最多 +12、客户需求额外最多 +3），避免无上限后数值失控。

## 12. UI / 表现

### 开始界面
- **动态背景**：滚动马路 + 角色在马路中间原地奔跑，背景速度 = 当前载具速度
- **开场演示**：5 名竞争对手 + 1 辆警车（下半屏巡逻）+ 1 辆大运（顶部露车头横扫）互相碰撞，会主动避开玩家
- 按钮：载具（含解锁态）/ 开始 / 排行榜；右侧展示 **UP 头像 + 开发视频封面**
- 按钮为斜向渐变 + 顶部柔光；悬停提亮、点击下沉；标题渐变描边

### 游戏内 HUD
| 位置 | 内容 |
| --- | --- |
| 左上 | 血量条（低血呼吸闪烁）+ 外卖数 + 金钱 |
| 左上（下） | 罪恶条 + 等级 |
| 左上（再下） | 大运血条（存续时） |
| 顶中 | 暂停 / 音量 |
| 右上 | 当前速度(km/h) + 已行驶里程 |
| 右侧 | 客户距离与需求 |
| 右下 | 吃外卖 / 冲刺、投掷（有毒=绿、无毒=黄） |
| 右侧上 | 装备栏（持有道具与余量） |

## 14. 技术架构

```
index.html          按依赖顺序加载 src/ 下全部脚本
src/core/     utils config state canvas assets audio toy input
src/entities/ player enemy police customer shop pickup boss
src/systems/  collision zone weapons gameflow unlock
src/fx/       smoke boom floattext menuact
src/ui/       hud
src/main.js   update / render 主循环 + 道路滚动
```

**约定**
- 贴图尺寸按 `naturalWidth/Height` 动态计算；`detectSpriteBox` 剔除透明留白（多帧只取第一帧）
- **加载优化**：音频延迟加载（大文件 `preload=none`，首次交互后再拉）；非核心贴图（店铺/客户/大运）在 `ready` 之后加载
- 打包：Toy 包为 zip，`index.html` 在根、相对路径、条目正斜杠
