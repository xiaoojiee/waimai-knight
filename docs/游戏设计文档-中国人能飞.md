# 《中国人能飞》游戏设计文档

> 魔改经典 Flash 游戏《打企鹅（Yeti Sports: Pingu Throw）》｜ 2D 横版飞行距离挑战 ｜ H5 / B站 Toy

---

## 0. 立项背景与切入点

**一句话**：把当年“打企鹅”的爽感，换成一整套中国互联网梗——“中国人能飞”。

**文化锚点（参考素材）**
- 经典玩法原型：魔改《打企鹅》 https://www.bilibili.com/video/BV1qT421C7sd
- 梗来源：【中国人能飞是什么梗【梗指南】】 https://www.bilibili.com/video/BV14x3u6iEvc/
- 梗传播：【中国人能飞🚀🚀🚀】 https://www.bilibili.com/video/BV1iKgv6HEgJ/

**为什么成立**
1. 原型玩法人人玩过，操作门槛为零：**卡时机、看距离、比分数**。
2. 梗自带喜剧张力（“中国人能飞”本身就是荒诞梗），适合做夸张的物理与演出。
3. 天然适合排行榜 / 分享成绩，符合 B站 Toy 的传播场景。

**设计基调**：荒诞、爽快、短平快（单局 1~3 分钟）、失败也不憋屈（有续关）。

## 2. 核心循环

```
揽佬从上方落下 → 神🦅哥卡准时机摆架势击打 → 揽佬向左飞出去
   → 按住屏幕抬高角度、吃道具、穿风眼 → 落地
   → 速度够：卡时机「打水漂」继续飞（次数 +1）
   → 速度不够：神🦅哥再现，再打一次（续关）
   → 结束：结算分数（角度完美度 × (距离 × 水漂次数 + 道具分)）→ 上传排行榜
```

**爽点节奏**：击打（爆发）→ 飞行（掌控）→ 水漂（二次爆发）→ 续关（反转）→ 结算（比数字）。

---

## 3. 操作

| 输入 | 作用 |
| --- | --- |
| 按下屏幕 / 空格 | ① 起飞阶段：摆架势击打 ② 飞行阶段：**按住抬高飞行角度** ③ 落地阶段：打水漂 |
| 松开 | 停止抬高，角度自然回落 |
| 滑动 | 飞行阶段微调（可选，优先只做按住） |
| 触屏 | 全屏单指操作（无虚拟摇杆，降低门槛） |

> 设计原则：**全程只有一个操作键**。所有乐趣来自“时机”，而不是“操作复杂度”。

## 4. 玩法系统

### 4.1 起飞（神🦅哥击打）

- 揽佬从屏幕上方随机横向位置落下（有节奏的摆动），玩家控制底部神🦅哥的站位与架势
- 在**判定窗口**内按下 → 击打；按下的时机决定：

| 判定 | 窗口 | 初速倍率 | 角度加成（完美度） |
| --- | --- | --- | --- |
| 完美 | ±40ms | 1.0 | **×2.0** |
| 优秀 | ±90ms | 0.95 | ×1.5 |
| 普通 | ±160ms | 0.85 | ×1.0 |
| 勉强 | ±260ms | 0.7 | ×0.7 |
| 落空 | 超出 | 揽佬砸地，本局直接结束（或 -1 命） |

- **击打角度**：架势在“上勾 / 平推 / 下压”之间随按住时长变化，影响初始发射角（-10° ~ +35°）
- 初速（px/s）与发射角共同决定飞行轨迹；屏幕给出**角度指示器**帮助理解

### 4.2 飞行

**基础物理（每秒）**
| 量 | 规则 |
| --- | --- |
| 重力 | 恒定向下，约 `+900 px/s²` |
| 空气阻力 | 水平速度每秒 ×0.985（不额外操作时缓慢降速） |
| 抬角 | 按住时给向上的加速度，角度上限 **+25°**；持续按住会消耗“气力”，气力空则抬不动 |
| 气力 | 满值 100，抬起消耗 22/s，松开恢复 15/s |

- **不接触风眼/道具时**：揽佬持续下坠并降速 —— 逼玩家主动寻找交互物
- **接近地面**：出现高度预警线

**飞行环境**
- 空中随机分布：道具、风眼、障碍（其他飞行者）
- 风眼（上升气流）：接触后在圈内获得持续升力 + 速度不衰减，持续 1.5s
- 高度上限：飞太高触发“稀薄空气”（抬升效率减半），避免无限贴顶

### 4.3 落地

| 情况 | 判定 | 结果 |
| --- | --- | --- |
| 触地时水平速度 ≥ **320 px/s** | 落地瞬间弹出「打水漂」时机环（±120ms） | 命中 → 以**相同速度**重新起飞，水漂次数 +1，并获得短暂无敌 |
| 触地时速度 < 320 px/s | 直接结束本次飞行 | 进入结算 / 续关判定 |

- 打水漂失败（时机偏差过大）→ 速度衰减 40% 后继续下滑，通常导致结束
- 水面/地面/屋顶等不同地块对判定有细微差别（水面更好弹）

### 4.4 续关（神🦅哥再现）

- 条件：飞行距离 ≥ **800m** 后，因速度不足落地
- 演出：神🦅哥从天而降，再次击打揽佬
- 代价：每次续关**分数乘区递增惩罚**（第 1 次 ×0.9，第 2 次 ×0.8 ……），给出“续关有代价”的取舍
- 次数上限：默认 **2 次**（可通过道具/成就提升）

### 4.5 计分

```
最终得分 = 角度完美度倍率 × ( 飞行距离(m) × 水漂次数 + 道具加分 )
```

| 项 | 计分 |
| --- | --- |
| 飞行距离 | 1 分 / m |
| 水漂次数 | 乘数（0 次记 1；每多一次 +1，最高计入 8） |
| 金币 | +10 / 枚 |
| 妙脆角 | +15 / 个 |
| 风眼 | +30 / 次 |
| 彩虹猫陪飞 | +50 / 次 |
| 续关惩罚 | 每次 ×0.9（衰减） |

> 关键设计：**距离 × 水漂**是乘算，鼓励玩家为了多打一次水漂而接受低空飞行风险。

## 5. 空中道具

| 道具 | 效果 | 备注 |
| --- | --- | --- |
| 金币 | 加分（+10） | 基础收集物，密集排列成轨迹 |
| 东风导弹 | 获得直线向前加速，飞一段固定距离 | 期间**无法调整飞行角度**（高风险高收益） |
| 云层肚皮 | 落地时无视落地角度，直接再次起飞 | 相当于保底一次水漂 |
| 红色围巾 | 获得后**自动吸取周围金币**（半径 220px） | 持续到本次飞行结束 |
| 其他飞行者 | 其他国家的飞行者从四面飞来 | **碰到直接坠机**，需躲 |

**道具投放规则**：沿飞行轨迹前置生成，保证“看得见、够得着”；风眼与导弹交替出现，形成节奏。

## 6. 飞行事件（需累积一定距离才触发）

| 事件 | 触发距离 | 内容与效果 |
| --- | --- | --- |
| 妙脆角雨 | ≥ 400m | 天空下起妙脆角，穿过即收集（+15/个），密集段可连吃 |
| 彩虹猫陪你飞 | ≥ 900m | 身后出现彩虹轨迹；接触到彩虹猫后**移动速度不再衰减** |
| 黑龙也是龙 | ≥ 1500m | 云中钻出黑龙并行飞行；躲开它，撞到则坠机；成功穿过 +100 |
| 中国天上有好多神仙 | ≥ 2500m | 神仙列队出现（只在“China 版图”范围内），给出祝福：**5 秒无敌 + 抬角不耗气力** |

事件之间保持 ≥ 300m 的冷却，避免堆叠。

## 8. 难度与进度曲线

| 机制 | 规则 |
| --- | --- |
| 重力递增 | 每 1000m 重力 +4%（上限 +60%） |
| 气力上限 | 随距离缓慢下降（越远越难抬角），最低 60 |
| 障碍密度 | 其他飞行者数量随距离增加（3 → 12） |
| 风眼密度 | 略降，迫使玩家学会取舍 |
| 速度基准 | 原地形不变，但打水漂速度阈值每 2000m +20 |

**目标**：新手能飞到 500~1000m；熟练 3000m；高手 10000m+。

## 9. 失败与结束

| 结束方式 | 触发 |
| --- | --- |
| 坠机 | 撞到其他飞行者 / 打水漂失败且速度耗尽 |
| 着陆 | 速度 < 阈值且无续关机会 |
| 落空 | 起飞阶段完全没打到揽佬（直接结束） |
| 出界 | 飞太高“稀薄空气”后强制下坠（不算失败，但会损失距离） |

结算页展示：**飞行距离 / 水漂次数 / 金币 / 完美击打加成 / 最终分数**，并提供「再来一次」「分享成绩」「查看排行榜」。

## 12. 技术架构（建议）

```
index.html
src/core/      utils config state canvas assets audio input toy
src/entities/  eagle(神鹰哥) lanlao(揽佬) coin missile cloud scarf rival
               windeye event scenery
src/systems/   physics(重力/阻力/抬角) hit(时机判定) skip(水漂判定)
               spawn(道具/事件投放) score(计分) gameflow(流程/续关)
src/fx/        trail(彩虹轨迹) splash(水花) impact(击打特效) floattext
src/ui/        hud menu result(结算) gallery(梗图鉴) rank
src/main.js    update / render 主循环 + 视差滚动
```

**关键技术点**
1. 物理用固定步长积分（`1/120s` 子步），保证不同帧率判定一致
2. 时机判定基于**输入时间戳 vs 命中窗口**，不依赖渲染帧
3. 风景用**视差图层 + 程序化生成**（远山/云/星空），避免大量贴图
4. 资源按需加载（音频 `preload=none`，远景贴图 `ready` 后再拉）
5. B站 Toy：`submitScore` 上传分数、`getQrCode`/`share` 做成绩分享、`getUserProfile` 展示昵称头像

## 15. 待办 / 风险

1. **物理手感是生死线**：需尽早用灰盒验证“按住抬角”是否有趣
2. 打水漂窗口过宽会没有成就感，过窄会挫败 —— 需要 3 轮可玩性测试
3. 梗的版权与尺度：优先用“梗的意象”（可自绘），避免直接使用他人素材
4. 视差风景量大，需程序化 + 复用，控制包体
5. 排行榜防刷：分数做服务端校验（距离 × 水漂 × 倍率的合理区间）
