# 你的胆子真的是肥嘟嘟的

一款 2D 俯视角 H5 外卖骑手游戏。玩家扮演外卖骑手,在循环道路上行驶,躲避敌方骑手与警车,送外卖赚钱,购买武器武装自己。

- 纯原生 Canvas 2D,无框架、无构建
- 桌面:WASD / 方向键;手机:屏幕下半区虚拟摇杆
- 逻辑分辨率 480×800,自适应缩放
- 在线地址:https://xiaoojiee.github.io/waimai-knight/

---

## 一、玩法系统

### 1. 骑手与速度
- 道路无限循环滚动,场景以默认速度 `BASE_SPEED` 前进
- **W/↑**:向前冲(场景更快);**S/↓**:刹车(场景更慢),速度范围 30~410
- 侧倾动画随横向移动
- 车尾烟雾随速度增多(烟雾图集 0-0 帧)

### 2. 敌方骑手
两种生成方式:
- **前方被超越**:从屏幕上方入场,速度远慢于场景,被玩家追上甩掉
- **后方超车**:从屏幕下方入场,速度快于玩家,反超而去

特性:
- 头顶血条(30 HP)
- 轻微左右游走;施工路段会自动避让(带武器的敌人无视)
- 前 200 米不带武器;之后按难度概率 10%→60% 随机携带 1 件装备(匕首/手枪/步枪/盾牌)
- 持枪敌人自动瞄准玩家开火(手枪 8 伤/1.2s,步枪 10 伤/0.9s,弹速 300,散布 ±0.22rad)
- 盾牌可格挡若干次
- 同屏上限随难度 3→10

### 3. 碰撞与伤害
- **侧面相撞**:双方各 15 伤害
- **前后相撞**:前方(世界前进方向)受伤 24,后方 8
- 双方受击无敌 0.2s;玩家受击红色蒙板+屏幕震动
- 敌方死亡(HP≤0):统一撞飞动画(向前上方翻滚+放大淡出)+碰撞特效(图集 3-3)+掉落外卖
- 玩家 HP≤0:死亡,退回开始界面

### 4. 外卖与回血
- 初始背负 3 个外卖;敌方死亡掉落 2~3 个(向空间开阔侧斜着撒出,带向前惯性)
- **拾取的外卖堆叠在骑手背上**(无限堆叠,新捡的盖在上面,上方盖住下方 4/5)
- 右下角"回血"按钮:**消耗最下面(最早捡的)1 个**回 25 HP
- 客户结算同样从最下方开始消耗

### 5. 客户与金钱
- 路边客户按里程调度(前 120 米不出现,之后每 60~150 米概率 60% 刷新)
- 头顶气泡显示需求外卖数:前 250 米 1~2 个,之后每 500 米需求升一档(最高 4+4+难度加成)
- 经过客户结算:**达标** → 每份赚 20;缺货 → 每份罚 8
- **金钱 < 0 → 破产死亡**
- HUD 提示下一个客户距离

### 6. 店铺与装备
- 店铺随机刷新在右侧水泥地面(色块占位,贴图 3×3 图集)
- 骑到水泥区对应店铺视为购买:
  | 装备 | 价格 | 效果 |
  |---|---|---|
  | 匕首 | 40 | 20 次撞击 +15 伤害,挥砍动画 |
  | 手枪 | 70 | 6 发自动瞄准开火,12 伤害/0.45s |
  | 步枪 | 120 | 15 发,15 伤害/0.3s |
  | 盾牌 | 60 | 3 次完全格挡 |
- 枪械互斥(买新枪自动卸下旧枪);不同种类装备可同时持有
- 装备图标绕骑手旋转;枪械自动瞄准最近的敌人开火

### 7. 饭店
- 随机刷新在水泥区:一次性购买 **5 个外卖**,一家只卖一次

### 8. 施工路段
- 占用半条车道,黄色斜向条纹提示
- 两端各立一块警告牌,可被玩家撞飞(翻滚+重力+淡出)
- 敌方骑手避让占用车道(带武器者无视)
- 玩家在施工区内 → 犯罪条增长 14/s

### 9. 犯罪条与警察
- **犯罪条**(太刀气刃槽式 1~4 级):超速(平方曲线)与进入施工区都会攒槽
- 槽满自动升一级并清零;停止犯罪 2 秒后衰减,槽空降级
- **2 级**:1 辆警车在道路底部跟踪,间歇前冲撞击(33 伤害)
- **3 级**:2 辆警车,冲撞时机错开(两边各一辆)
- **4 级**:路面撒拦车钉,压到 → 扎胎:减速至 55%,刹车更灵,4 秒
- 警车可撞飞敌方骑手(秒杀)

### 10. 难度曲线
- `difficulty = min(1, 里程/4km)`,满难度时:
  - 敌人同屏上限 3→10,生成间隔缩短 60%
  - 施工路段/客户/店铺刷新率提升
  - 客户需求额外 +0~3 个
  - 敌人带武器概率 10%→60%

### 11. 流程与 HUD
- 黄色开始界面(点开始按钮才开局,开局暂停)
- 死亡/破产 → 结束界面 → 退回开始界面(完全重置)
- HUD:左上 HP/金钱/犯罪条;右上 速度/里程;右下 回血按钮与装备状态

## 二、操作方式

| 输入 | 动作 |
|---|---|
| W / ↑ | 加速前进 |
| S / ↓ | 刹车减速 |
| A/D / ←/→ | 左右移动 |
| 手机下半屏滑动 | 虚拟摇杆(同 WASD) |
| 点击回血按钮 | 消耗 1 个外卖回血 |
| 点击开始按钮 | 开始游戏 |

**测试快捷键**(开发用):
- `+` / `-`:调整犯罪等级
- `1~4`:直接获得 匕首/手枪/步枪/盾牌
- `5`:+5 个外卖
- `6`:+1 有毒外卖
- `7`:+1 特殊外卖(随机)
- `8`/`9`/`0`:触发特殊效果 我超勇的 / 水果摊 / 焖子
- `P`:现有食物全部变有毒(鸡汤来咯)
- `T`:路程 +500 米(快速进入高难度)

## 三、技术架构

### 文件结构
```
index.html                入口, 按依赖顺序加载 21 个脚本
assets/贴图/              游戏贴图(降采样压缩后)
src/
├── core/
│   ├── config.js         全部常量
│   ├── canvas.js         Canvas 初始化与 DPR 缩放
│   ├── state.js          全局状态(game/player/input/BOUNDS)
│   ├── assets.js         贴图加载与 ready 状态
│   ├── input.js          键盘/虚拟摇杆/按钮点击/测试键
│   └── utils.js          工具函数(clamp/圆角/难度系数)
├── entities/
│   ├── player.js         玩家受击与绘制
│   ├── enemy.js          敌方骑手(生成/更新/受击/绘制/子弹)
│   ├── pickup.js         外卖掉落/拾取/回血
│   ├── customer.js       客户(调度/需求/结算/绘制)
│   ├── shop.js           店铺与饭店(购买/绘制)
│   └── police.js         警车与拦车钉
├── systems/
│   ├── collision.js      碰撞结算(侧/前后伤害/撞开)
│   ├── zone.js           施工路段与警告牌
│   ├── weapons.js        玩家装备(瞄准/开火/挥砍)
│   └── gameflow.js       游戏流程(开始/结束/重置)
├── fx/
│   ├── smoke.js          车尾烟雾粒子
│   ├── boom.js           碰撞特效(图集 3-3)
│   └── floattext.js      漂浮文字
└── ui/
    └── hud.js            HUD 与按钮
```

### 架构约定
- **经典 `<script>` 全局共享**:无模块系统,跨文件引用用 `/* global xxx */` 注释声明
- 脚本按依赖顺序加载(常量 → 状态 → 资源 → 工具 → 实体 → 系统 → 特效 → UI → 主循环)
- 贴图可选加载:道路/骑手必需(加载完才 ready),其余可选,缺失时回退矢量绘制
- 贴图降采样:原图放 `assets/贴图原图/`(gitignore),游戏内用 `assets/贴图/` 的压缩版
