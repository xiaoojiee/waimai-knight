# 你的胆子真的是肥嘟嘟的

2D 俯视角 H5 送餐游戏(demo v1.3),原生 Canvas 实现,无任何框架依赖,单机即玩。

## 运行方式

- 直接双击 `index.html` 即可游玩
- 或使用 VSCode 插件 **Live Preview**(右键 → Show Preview)/ **Live Server**
- 手机试玩:本地起服务后同网访问(如 `npx serve`),或 F12 设备模拟

## 操作

| 方式 | 操作 |
|---|---|
| 电脑 | 方向键 / WASD 移动;↑ 加速,↓ 减速 |
| 手机 | 屏幕下半区路面滑动(虚拟摇杆);右下角水泥区按钮吃外卖回血 |
| 测试键 | `+`/`-` 调犯罪等级;`1`~`4` 获得装备(匕首/手枪/步枪/盾牌);`5` 外卖 +5 |

## 玩法

- **送餐**:路边客户需求外卖,右侧面板显示距离与需求量;送达赚钱(15/个),缺货罚款(8/个),金钱低于 0 破产死亡
- **战斗**:敌方骑手阻扰(前方被超越 / 后方超车两种),侧面相撞双方同伤、前后相撞前方受伤更多;敌人死亡掉落外卖,死亡动画放大淡出;被玩家撞死或被警车撞飞时向前上方翻滚飞出并提示「撞飞!」
- **装备**:水泥区店铺出售匕首/手枪/步枪/盾牌,**不同种类可同时持有**;手枪步枪自动瞄准自动开火,匕首撞击加伤,盾牌格挡
- **饭店**:花 $50 一次性买 5 个外卖(一家限购一次)
- **施工路段**:黄色斜纹占半边车道,首尾警告牌可撞飞;敌方骑手避让、玩家可硬闯
- **犯罪系统**(太刀气刃槽式):闯施工车道/超速攒犯罪槽,槽满自动升一级并清槽(最高 4 级, HUD 显示「犯罪 Lv×」);停止犯罪后槽衰减,槽空降一级;等级 2 一辆警车持续跟踪间歇冲撞、等级 3 两辆错开冲撞、等级 4 前方随机铺拦车钉(碾过扎胎,整体减速且刹车更灵);警车撞到玩家扣 1/3 血量,撞到敌方骑手直接撞飞秒杀

## 项目结构

```
demo1/
├── index.html          # 页面(样式 + 画布 + 按序加载 src 下 21 个 script)
├── src/
│   ├── main.js         # 主循环(update/render) + 道路贴图滚动
│   ├── core/           # 基础层: 常量/工具/状态/画布/贴图加载/输入
│   ├── entities/       # 实体: 玩家/敌骑手/警车+路钉/外卖/客户/店铺+饭店
│   ├── systems/        # 系统: 碰撞/装备/施工路段/游戏流程
│   ├── fx/             # 特效: 烟雾/碰撞/漂浮文字
│   └── ui/             # 界面: HUD/虚拟摇杆/结束界面
├── assets/贴图/        # 全部贴图资源(道路/骑手/敌骑手/客户/道具/烟雾/碰撞/外卖/警告牌/警车/路钉)
├── package.json        # npm 脚本: lint / format / check
├── eslint.config.mjs   # ESLint 配置(各文件顶部 /* global */ 声明跨文件引用)
├── .prettierrc         # 代码风格
├── .vscode/settings.json # 保存时自动格式化
└── README.md
```

## 开发

```bash
npm install       # 安装开发依赖(仅用于代码检查, 玩游戏不需要)
npm run check     # ESLint + Prettier 检查
npm run format    # 自动格式化
npm run lint      # 仅 ESLint
```
